#+title: Remote Browser

A Linux-based remote browser management system written in modern C++.

The goal of this project is to explore Linux process management, browser automation, inter-process communication, and security isolation while building a practical foundation for a secure remote browsing solution.

** Goals
- Manage browser processes through Linux system calls.
- Implement reliable process lifecycle management.
- Integrate Chromium and the Chrome DevTools Protocol (CDP).
- Explore process isolation and security boundaries.
- Build communication mechanisms for remote browser interaction.
- Apply modern C++ design principles and Linux systems programming.

** Development Environment
This project uses Nix to provide an isolated and reproducible development environment.

Enter the environment:
#+begin_src sh
nix-shell
#+end_src

The development shell provides the compiler, build tools, debugger, testing framework, and other development dependencies.
